# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Unity 2022.3.62f3 mini-game project. Early stage: the only gameplay code so far is
`Assets/Scripts/PlayerMovement.cs` (click-to-move via `NavMeshAgent` + camera raycast onto
terrain). Everything else under `Assets/` is sample/scaffold content (`TerrainSampleAssets/`,
`TutorialInfo/`) or generated URP/HDRP render settings.

## Working through Unity (unity-mcp)

This project is driven through the `unity-mcp` plugin, not a headless CLI. There is no
`dotnet build`/`msbuild` workflow to invoke by hand — the Editor owns compilation. Use the
`unity_*` MCP tools for everything:

- On the first tool call instances are auto-discovered. If more than one Unity Editor is
  running, ask the user which to use and call `unity_select_instance` before proceeding.
- After editing C#, the Editor recompiles automatically. Check results with
  `unity_get_compilation_errors` (survives console clears — prefer it over `unity_console_log`
  for compile issues).
- Run/inspect play mode with `unity_play_mode`; capture what the player sees with
  `unity_graphics_game_capture`.
- Prefer `unity_*` tools over editing scene/prefab/asset YAML by hand — GUIDs and fileIDs are
  fragile. Editing `.cs` files under `Assets/Scripts/` directly is fine.
- The `.csproj`/`.sln` files at the root are Unity-generated for IDE IntelliSense. Do not
  hand-edit them; they are regenerated by the Editor.

## Tests

`com.unity.test-framework` is installed but no tests exist yet. Run tests via the Unity Test
Runner (Window > General > Test Runner) or the MCP menu-item tools — not via an external test CLI.

## Render pipeline

Both URP (`com.unity.render-pipelines.universal`) and HDRP are present in `Packages/manifest.json`,
but the active pipeline is **URP** — `ProjectSettings/GraphicsSettings.asset` points at a URP
asset, and quality tiers live in `Assets/Settings/` (`URP-Performant`, `URP-Balanced`,
`URP-HighFidelity`, each with a matching `-Renderer`). Author shaders/materials for URP. The
HDRP resources under `Assets/HDRPDefaultResources/` and `TerrainSampleAssets/` come from the
terrain sample and are not the active path.

## Navigation

Click-to-move depends on baked NavMesh data (`Assets/Scenes/SampleScene/NavMesh-NavMesh.asset`)
and the `com.unity.ai.navigation` package. Terrain or layout changes that affect walkable
surfaces require re-baking the NavMesh, or `PlayerMovement` will fail to path.
