## ground 下 Cube 拼接 + 坐标取整
- 场景：`Assets/Scenes/SampleScene.unity`（约 14MB，LF 换行）
- ground（GameObject fileID 2144822833 / Transform 2144822834，位置 {47.42848, -43.203217, -23.352045}）下挂了 5120 个 1×1×1 的 Cube，局部坐标均为非整数。
- 分析发现三轴小数偏移高度统一（x≈0.14638, y=0.86682, z≈0.09959，差异仅 1e-6 浮点误差），即立方体本就在"整数网格+固定偏移"上。
- 操作：用 Python 脚本把每个 Cube 的 m_LocalPosition 四舍五入到最近整数（只改这一行，其余字节/换行原样保留）。ground 自身位置未动。
- 结果：5120 个 Cube 全部整数坐标，5120 个不同格子，0 重叠；铺成 64(x:-79..-16) × 80(z:-46..33) 的完整平面，y 全部=43。
- 备份：`D:/unity/Miniproject/SampleScene.unity.bak`
- 注意：若 Unity 当时正打开该场景，回到 Unity 时会提示"场景被外部修改，是否重新加载"，选 Reload 即可看到拼接结果。
